----------------------------------------------------------------------
IoT Agent System: Simplified Architecture Diagram
----------------------------------------------------------------------

1. ユーザー (Chat UI / Browser)
   - 自然言語で指示を送信

   ↓ (HTTP POST)

2. IoT Agent サーバー (Flask)
   - API Gateway / コントローラー
   - Cloud LLM (OpenAI / Gemini) に意図解釈を依頼
   - JSON形式のジョブを生成し、ジョブキューに追加

   ↓ (ポーリング)

3. エッジデバイス

   A. Raspberry Pi Pico W (シンプルな実行者)
      - サーバーから単純なコマンド (例: サーボ角度=90) を受信
      - ハードウェアを直接制御し、結果をサーバーに送信

   B. Jetson / Raspberry Pi 4 (スマートな実行者)
      - サーバーから高度なジョブ (例: 画像解析) を受信
      - ローカルのLLM/AIモデルを使用して処理を実行
      - 結果をサーバーに送信

----------------------------------------------------------------------
主な違い:
- Pico W: シンプルなリモート制御に特化。
- Jetson / RPi 4: ローカルAI処理やカメラ連携など、より複雑なタスクを実行可能。
----------------------------------------------------------------------
